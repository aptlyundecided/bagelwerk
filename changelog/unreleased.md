# Unreleased

- Added the **Record Store** (`src/core/records/`): every Flow run, Node run, acceptance, Flow event, agent run (all harnesses), agent event, agent file and supervisor report is now also written to a Postgres-compatible database (embedded PGlite under `.artifacts/records/`, real Postgres via `BAGELWERK_RECORDS=postgres://…`). New `npm run records -- <serve|status|migrate|ingest|search|runs|show|sql|stats|materialize|embed|mcp>`. Full-text, fuzzy, node-path-scoped, semantic and hybrid search; read-only SQL; an MCP server for agents. Preflight and resume now treat the store as the authority for accepted results and rebuild `accepted/` from it when missing or stale. Credentials are redacted from stored text. Set `BAGELWERK_RECORDS=off` to opt out; the default test runner does.

- Added a **Codex harness** (`executeCodexAgentNodeSession` in `src/core/agent-execution/codexAgentCore.ts`) that runs `codex exec --json`, sends the prompt on stdin, records raw events plus projected run events in the Node observation directory, totals Codex token usage, and returns the final message, thread id, command/file-change counts and warnings. Sandboxing stays caller-owned through `execArgs` and a caller-supplied child `env`.
- Added harness-neutral run observability (`agentRunEvents.ts`): `AgentRunEvent` timeline steps streamed through `onRunEvent` and written to `run-events.ndjson`, `AgentTokenUsage`, `AgentRunError` (reason, observation dir, bounded stderr tail), and `runJsonlProcess` with timeout/abort that kills the CLI's process group.
- Extended the Claude Code harness without changing existing callers: `dontAsk` permission mode, `disallowedTools`, `extraArgs`, `signal`/`timeoutMs`, `observationRoot`, live `onRunEvent` projection (tool calls joined to their results), and native `tokenUsage`/`costUsd`/`numTurns`/`sessionId`/`resultText` parsed from the `result` event (the previous usage parser only recognised pi-shaped usage, so Claude Code token counts were never captured). The prompt now follows `--` so it cannot be read as a tool name.
- Made the platform-tour narrated playthrough genuinely model-free so the `GETTING-STARTED.md` "fresh clone → run a real Flow, no model cost" first step is true by construction. `npm run flow:tour -- --present [--auto]` now wires a deterministic `sampleTourRunAgent` (a canned, `dry-run/sample`-labelled note) on the agent-backed beats instead of the real `pi` CLI, so it spends no model quota and is CI-safe regardless of whether a harness is signed in. Added a `--live` (alias `--model`) flag that opts the presenter back into the real agent; the autonomous `npm run flow:tour` (no `--present`) is unchanged and still uses the real agent. Added `sampleTourRunAgent` to the platform-tour node seam and tests covering the offline/deterministic dry-run path. Updated `GETTING-STARTED.md` and `src/core/built-ins/platform-tour/README.md` to describe the model-free default and the `--live` opt-in.
- Removed the **PR Magic** built-in Flow package from the active built-ins surface and all code wiring: the `src/core/built-ins/pr-magic/` package, its run-profile metadata, and the `npm run flow:pr-magic` CLI are gone. `platform-tour` (`npm run flow:tour`) is now the sole active built-in and the worked example for new Flows. Updated tracked documentation to remove or repoint every PR Magic / `flow:pr-magic` reference — root `README.md`, `GETTING-STARTED.md`, `CONTEXT.md`, `UBIQUITOUS_LANGUAGE.md`, `src/core/README.md`, `src/core/built-ins/README.md`, `src/core/built-ins/platform-tour/README.md`, the `src/core/flow-runner/README.md` and `flow-runner-core` `api/about.md` + `tests/about.md` files, `src/core/notifications/README.md`, `src/tools/flow-runner/ink/README.md`, the `platform-tour` `nodes/summarize.ts` reference, the `mermaid-graph-viewer` and `handoff-risk-review` skill docs across all mirrored surfaces, the `version-release` skill, and `.env.example`; the removal is recorded in `src/core/built-ins/README.md`. Historical release notes under `changelog/releases/` are intentionally left intact as immutable release history.
