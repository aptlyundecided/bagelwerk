# 0.4.3 - 2026-11-28

- Ask a model for a structure and get it back parsed. Pass `outputSchema` to the Claude Code, Codex or Ollama harness and read `result.structured`; the schema goes to the provider (Claude Code `--json-schema`, Codex `--output-schema`, Ollama `format` or a `reply` tool), so the model's formatting can no longer fail a run by itself.
- New Ollama harness, `executeOllamaChatNodeSession`, for local Ollama and Ollama Cloud. It records the stop reason, reasoning text and token counts, and throws on empty or cut-off replies instead of returning them. On Ollama Cloud, which ignores `format`, structured replies use a `reply` tool by default.
- Every failed model call is labelled `transport`, `contract` or `node` (`AgentRunError.failureClass`, `classifyAgentFailure`, and `failureClass` in `failure.json` and `summary.json`), so a broken call or unreadable reply is not mistaken for bad reasoning. New `AgentRunError` reasons: `http`, `empty-output`, `truncated`.
- `executeClaudeCodeAgentNodeSession`, `executeCodexAgentNodeSession`, `executeOllamaChatNodeSession`, `AgentRunError`, `classifyAgentFailure` and `readStructuredReply` are now exported from `bagelwerk`.
